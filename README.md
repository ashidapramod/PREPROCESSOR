# PREPROCESSOR
This project implements a basic C Preprocessor using the C programming language. It demonstrates the fundamental preprocessing operations performed before the actual compilation of a C program.

## Features

The project implements the following preprocessing operations:

1. Comment Removal
    Removes single-line comments ("//").
    Removes multi-line comments ("/* ... */").

2. File Inclusion
    Handles header file inclusion using "#include".
    Processes included header files.

4. Macro Substitution
    Identifies macro definitions using "#define".
    Replaces macro names with their corresponding values.

   
## How to Run the Project
 1.Compile the Project
              - make

2.Run the Preprocessor
- ./mypreprocessor output.c
- vi output.i
